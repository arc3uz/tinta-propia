Tinta Propia es software libre bajo licencia MIT. Incluye o utiliza los siguientes componentes de terceros.

## Aplicación y librerías

| Componente | Uso | Licencia |
|---|---|---|
| [Tauri](https://tauri.app/) | Contenedor de escritorio, diálogos, archivos y ventana | MIT o Apache-2.0 |
| [Rust](https://www.rust-lang.org/) | Backend, PDF y sistema de archivos | MIT o Apache-2.0 |
| [CodeMirror 6](https://codemirror.net/) | Editor Markdown | MIT |
| [Mermaid](https://mermaid.js.org/) | Diagramas | MIT |
| [Vite](https://vite.dev/) | Build del frontend | MIT |
| [Crates de Rust](https://crates.io/) | Dependencias del backend | Principalmente MIT o Apache-2.0; ver `src-tauri/Cargo.lock` |

Los textos completos de las licencias de las dependencias están en sus propios paquetes y repositorios. El archivo `src-tauri/Cargo.lock` y `package-lock.json` fijan las versiones utilizadas.
